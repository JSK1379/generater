# Near Ride 使用者指南

Near Ride 用 BLE 發現附近使用者，接受連線後可透過網路聊天室互動；GPS 與 AI 功能皆為可選功能。

## 第一次使用

1. 開啟 App 並建立帳號。
2. 設定暱稱與個人資料。
3. 依需要允許藍牙、定位與通知權限。
4. 進入「設定」決定是否開啟 BLE 廣播與背景 GPS。

## 藍牙探索

- 「藍牙」頁會掃描附近同樣使用 Near Ride 且正在廣播的裝置。
- 點選使用者後可發送連線請求。
- 對方接受後，系統會建立或開啟聊天室。
- 若掃描不到其他人，請確認雙方藍牙、權限及 BLE 廣播都已開啟。

## 聊天

- 「聊天室」頁會列出目前已建立的聊天房間。
- 訊息透過 Near Ride 後端的 WebSocket 傳送。
- 網路中斷時，部分即時功能可能暫時無法使用。

## AI 助手與 AI 頭像

AI 功能由 Near Ride 後端統一呼叫 Gemini。**手機端不需要、也不應輸入 Gemini API Key。**

- 聊天 AI：提供回覆、摘要或情緒分析等輔助功能。
- AI 頭像：在個人資料頁描述外觀與風格後，由後端產生頭像。
- 若 AI 功能顯示不可用，通常代表伺服器端尚未設定 `GEMINI_API_KEY` 或 AI 服務暫時無法連線。

## GPS 背景追蹤

GPS 功能可隨時關閉。

1. 前往「設定」。
2. 開啟背景 GPS。
3. 選擇更新間隔。
4. Android 可能要求背景定位與通知權限。

高頻 GPS 測試頁屬於測試工具；一般使用不需要開啟高頻模式。

## 個人資料與頭像

個人資料頁可修改暱稱、基本資料、興趣與頭像。頭像可以從裝置選擇，或使用後端 AI 頭像功能產生。

## 常見問題

### 為什麼掃描不到其他人？
請確認藍牙已開啟、Near Ride 已取得藍牙/定位權限，且對方也已開啟 BLE 廣播。

### 為什麼聊天室連不上？
聊天需要網路及 Near Ride 後端 WebSocket。若伺服器正在重新部署，稍後重新連線即可。

### 為什麼背景 GPS 沒有記錄？
請檢查定位權限、背景定位權限、Android 前景服務通知，以及設定頁中的 GPS 開關。

### 需要自己申請 Gemini API Key 嗎？
不需要。正式架構只允許伺服器保存 AI 金鑰。

## 隱私提醒

BLE 廣播與 GPS 都會處理與附近裝置或位置相關的資訊。只在需要時開啟功能，並依實際用途管理權限與資料保留方式。
